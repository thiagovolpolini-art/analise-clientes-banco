# 📊 Análise de Clientes Bancários

Projeto de análise exploratória de dados de clientes bancários utilizando Python.

## 🛠️ Tecnologias utilizadas

- Python
- Pandas
- Plotly
- Google Colab

## 🎯 Objetivo

Analisar os dados dos clientes de uma instituição bancária, explorando informações e padrões presentes na base de dados.

## 📈 Análises realizadas

O projeto utiliza técnicas de análise exploratória de dados (EDA), incluindo tratamento e visualização dos dados.

> Projeto desenvolvido para prática e aprendizado em Análise de Dados.
